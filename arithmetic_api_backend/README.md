# Arithmetic API Backend

Express API providing basic arithmetic operations.

## Run

```bash
npm install
npm start
```

Server listens on `process.env.PORT || 3001`.

## Endpoints

- `GET /health` → `{ "status": "ok", ... }`
- `POST /add` → `{ "result": number }`  
  Accepts either `{ "a": number, "b": number }` or `{ "numbers": number[] }`
- `POST /subtract` → `{ "result": number }` (accepts `{ "a": number, "b": number }`)
- `POST /multiply` → `{ "result": number }`  
  Accepts either `{ "a": number, "b": number }` or `{ "numbers": number[] }`
- `POST /divide` → `{ "result": number }` (accepts `{ "a": number, "b": number }`, `b !== 0`)

## Example curl commands

Health:

```bash
curl -s http://localhost:3001/health
```

Add (two numbers):

```bash
curl -s -X POST http://localhost:3001/add \
  -H 'Content-Type: application/json' \
  -d '{"a": 2, "b": 3}'
```

Add (many numbers):

```bash
curl -s -X POST http://localhost:3001/add \
  -H 'Content-Type: application/json' \
  -d '{"numbers":[1,2,3,4]}'
```

Subtract:

```bash
curl -s -X POST http://localhost:3001/subtract \
  -H 'Content-Type: application/json' \
  -d '{"a": 10, "b": 4}'
```

Multiply (many numbers):

```bash
curl -s -X POST http://localhost:3001/multiply \
  -H 'Content-Type: application/json' \
  -d '{"numbers":[2,3,4]}'
```

Divide:

```bash
curl -s -X POST http://localhost:3001/divide \
  -H 'Content-Type: application/json' \
  -d '{"a": 10, "b": 2}'
```

Division by zero (returns 400):

```bash
curl -s -i -X POST http://localhost:3001/divide \
  -H 'Content-Type: application/json' \
  -d '{"a": 10, "b": 0}'
```

Swagger UI is available at:

- `GET /docs`
- `GET /openapi.json` (generated by swagger-jsdoc at runtime via `/docs`, and also available as a static file under `interfaces/openapi.json` in the repo)
